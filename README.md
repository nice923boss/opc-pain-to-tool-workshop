# OPC 痛點到工具工作台

「OPC 一人公司 AI 實戰」兩天課程用的引導填寫網站。七張單子帶你把一個經營痛點寫成提案單、建議單、規格書，經過顧問桌、第一版、真實測試到交付，逐張檢查時數、驗收句與測試結果，最後產出《一人公司 AI 工具委託報告》，可下載 PDF。

- 工作台：https://nice923boss.github.io/opc-pain-to-tool-workshop/
- 學員提示詞手冊：https://nice923boss.github.io/opc-pain-to-tool-workshop/handbook.html （第二天開 `handbook.html#W5`）
- 填寫的資料只存在你自己的瀏覽器（localStorage），換電腦前請先「匯出進度」，到新電腦按「匯入進度」。PDF 是交件用的報告，不能匯回工作台。
- 診斷由固定規則產生，不是 AI 聊天機器人。
- 範例中的人物是虛構的；請填去識別化資料，不要放真實客戶個資。
